## 二、关键结论

1. 原论文 FSRCNN-s 已在软件中完整跑通，采用原始 `9x9` 转置卷积结构；它适合用于论文理解与软件画质对照。
2. 面向 FPGA 的轻量模型采用不同的 `PixelShuffle x2` 输出头，并已转换为 INT8 定点数据。它不是原论文 FSRCNN 的逐权重等价版本，但算力更低、接口更适合后续做流式硬件实现。
3. 以 `960x540 -> 1920x1080 @ 30 FPS` 估算，轻量 INT8 模型约为 `44.04 GMAC/s`；原版 FSRCNN-s 约为 `61.23 GMAC/s`。这说明原版模型更适合作为参考，而不是直接承诺在资源有限板卡上实时部署。
4. 软件视频管线可运行，但现有示例视频由 Set5 图片生成，只用于检查流程。最终答辩的量化结论应使用真实原生 1080P 视频，并以离线存在 HR 真值的测试集计算 PSNR/SSIM。

## 三、下一阶段可承担工作

1. 将 INT8 `3x3` 卷积拆解为 Line Buffer、Sliding Window、MAC、ReLU/PReLU、截位与饱和模块，先在仿真中与 Python Golden 逐点比对。
2. 设计 AXI4-Stream 风格的 `tvalid/tready/tuser/tlast` 数据接口，保证视频行、帧边界正确。
3. 搭建 PYNQ-Z2 的 PS-PL 控制：ARM/Python 侧负责模式和阈值配置；PL 侧执行流式插值和卷积增强。
4. 做三种模式对照：Bicubic、固定增强、自适应增强；记录 FPS、延迟、LUT/FF/BRAM/DSP 与离线 PSNR/SSIM。
