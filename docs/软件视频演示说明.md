# 软件视频演示说明

## 目的

在同一段模拟 540P Y 通道输入上运行 Bicubic、原论文 FSRCNN-s 与团队轻量 INT8 模型，生成上板前的视觉对照和逐帧指标。

## 跑通仓库保留的示例

```powershell
.\.venv\Scripts\python.exe scripts\make_set5_motion_source.py
.\.venv\Scripts\python.exe scripts\video_demo.py --input artifacts\video_demo\synthetic_set5_source_1080p.mp4 --max-frames 15 --device auto
```

## 跑真实视频

尽量使用原生 `1920x1080` 视频：

```powershell
.\.venv\Scripts\python.exe scripts\video_demo.py --input D:\your_1080p_video.mp4 --max-frames 150 --device auto
```

每次运行默认输出到 `artifacts/video_demo/<输入视频文件名>/`，不会覆盖仓库保留的示例结果。

## 输出内容

- `input_540p.mp4`：Bicubic 降采样后送入模型的 540P 输入；
- `bicubic_1080p.mp4`：传统插值基线；
- `original_fsrcnn_s_1080p.mp4`：原论文 FSRCNN-s 软件输出；
- `team_light_int8_1080p.mp4`：拟上板的轻量 INT8 模型输出；
- `comparison_2x2_1080p.mp4`：带文字标记的四路对照视频；
- `frame_metrics.csv`：每帧和平均 PSNR/SSIM；
- `summary.json`：输入、帧数、视频帧率、处理帧率、设备和平均指标。

## 证据边界

仓库保留的 `artifacts/video_demo/synthetic_set5/` 为 15 帧合成示例，只能证明解码、降采样、推理、编码和指标计算这条软件视频管线可运行；它不能作为最终画质结论。正式报告的 PSNR/SSIM 使用有 HR 真值的离线数据集，真实原生 1080P 视频用于视觉演示。
