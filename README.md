# FPGA 540P-to-1080P Video Super-Resolution Research

This repository contains my preliminary research for SRTP Direction 3, "Advanced Display FPGA Acceleration and Prototype Verification." It establishes reproducible software baselines, quality comparisons, quantized model data, and hardware-facing verification assets. It does not claim that an FPGA board-level real-time system is finished.

## Completed Work

1. **Original FSRCNN-s software reproduction**: reproduced the FSRCNN-s `(d=32, s=5, m=1)` architecture from Dong et al., *Accelerating the Super-Resolution Convolutional Neural Network* (ECCV 2016), including the original `9x9` transposed-convolution upsampling layer.
2. **FPGA-oriented INT8 model**: implemented a lightweight FSRCNN-style trunk with a `5x5 Conv + PixelShuffle x2` output head, then exported INT8 weights, INT16 activations, INT32 accumulations, and RTL-readable `.mem/.coe` files.
3. **Comparable evaluation**: compared Bicubic, original FSRCNN-s, and the lightweight INT8 model under the same T91 training / Set5 test / Y-channel / Bicubic-x2 protocol.
4. **Software video demo**: generated simulated 540P input, three 1080P reconstructions, a four-way comparison video, and per-frame PSNR/SSIM metrics.
5. **FPGA preparation package**: provided full-frame integer Golden data, small layer-by-layer test vectors, quantization parameters, and interface notes for follow-up RTL verification.

For a Chinese summary suitable for SRTP communication, see [Personal Results Overview](docs/个人成果总览.md).

## Scope and Boundary

| Item | Current status | Purpose |
| --- | --- | --- |
| Original FSRCNN-s | Software training and Set5 evaluation completed | Paper reproduction and quality reference |
| Lightweight INT8 FSRCNN-style model | Training, quantization, and Golden vector export completed | FPGA acceleration candidate |
| 540P-to-1080P software video path | Completed | Demo and pre-board comparison |
| Verilog, PYNQ-Z2 Overlay, HDMI board-level real-time demo | Not implemented yet | Next-stage work |

The current video result proves the software pipeline only, **not a completed real-time PYNQ-Z2 deployment**. The original FSRCNN-s and the lightweight INT8 model use different output structures and must not be presented as the same model.

## Reproduce

Python 3.10-3.12 is recommended. Training data is not committed; download it into `.data/` first.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# Download T91 and Set5, then train/evaluate original FSRCNN-s
.\.venv\Scripts\python.exe scripts\download_data.py
.\.venv\Scripts\python.exe scripts\reproduce_original_fsrcnn_s.py --epochs 50 --device auto

# Run tests
.\.venv\Scripts\python.exe -m pytest
```

To rebuild the lightweight model and its quantization package:

```powershell
.\.venv\Scripts\python.exe run_all.py
.\.venv\Scripts\python.exe scripts\verify_delivery.py
```

## Software Video Demo

The repository includes a short video synthesized from Set5 images to verify decoding, simulated 540P input, model inference, encoding, and metrics. It is a **pipeline smoke test, not a final quality result**.

```powershell
.\.venv\Scripts\python.exe scripts\make_set5_motion_source.py
.\.venv\Scripts\python.exe scripts\video_demo.py --input artifacts\video_demo\synthetic_set5_source_1080p.mp4 --max-frames 15 --device auto
```

For a native 1080P source video:

```powershell
.\.venv\Scripts\python.exe scripts\video_demo.py --input D:\your_1080p_video.mp4 --max-frames 150 --device auto
```

Each run writes to `artifacts/video_demo/<input file name>/` and does not overwrite the retained example. See [Video Demo Notes](docs/软件视频演示说明.md).
